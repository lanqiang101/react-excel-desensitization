# 隐数台：本地离线 CSV/XLSX 脱敏工作台

一个面向表格数据安全处理的本地前端工具，用于对 CSV / XLSX 文件中的敏感字段进行规则脱敏，并支持模型辅助扫描与结果预览确认后再下载。

适用于：

- 数据分析与报表分享
- 产品运营与 CRM 数据处理
- 学习案例、演示文稿和内部测试样例
- 需要在本地完成脱敏、但不希望上传文件的场景

## 功能概览

- 本地离线处理：文件只在当前浏览器内存中处理，不上传服务器。
- 批量导入：支持拖放或选择多个 `.csv` / `.xlsx` 文件。
- CSV 粘贴导入：可直接粘贴 CSV 文本，自动生成文件并进入处理流程。
- 内置样例：包含结构化 PII、格式变体、自由文本、误报陷阱、中文实体和脏数据等示例。
- 规则脱敏：内置手机号、身份证号、邮箱地址、详细地址、中文姓名和公司名称等规则。
- 脱敏模式：支持“替换 / 置空 / 随机”三种模式。
- 规则模板：支持标准个人信息、仅联系方式等模板切换。
- 混合扫描：正则负责确定性字段，MiniLM 模型负责辅助识别匿名文本中的敏感实体。
- 模型降级：模型资源缺失或加载失败时自动回退到规则引擎，不影响主流程。
- 结果预览：处理完成后先显示左右对比表格，审核确认后再下载。
- 下载控制：仅在用户确认预览无误后，才触发最终脱敏文件导出。
- 残留检查：在输出前进行敏感信息残留扫描，降低漏脱敏风险。

## 关键能力说明

### 1. 规则脱敏

当前默认支持以下字段类型：

- 手机号
- 身份证号
- 邮箱
- 地址
- 中文姓名
- 公司名称

系统会根据表头字段名识别列类型，并对匹配字段进行脱敏处理；同时也支持对具体字符串中的敏感信息做规则命中处理。

### 2. 模型辅助扫描

浏览器端支持本地 MiniLM 推理，主要用于检测文本字段中的隐私实体，例如：

- 中文姓名
- 地址
- 公司名称

模型运行策略：

- 先采用正则快速识别
- 对未命中区域执行模型检测
- 模型结果经过置信度阈值和黑名单过滤
- 未满足条件时自动放弃，避免误报

### 3. 预览确认下载

这是当前产品的关键交互：

1. 用户导入文件
2. 点击“开始脱敏”
3. 系统生成原始数据与脱敏数据双栏预览
4. 用户检查确认无误
5. 点击“确认并下载”导出最终文件

这样可以确保“先预览再下载”，避免误导出风险。

## 使用流程

1. 在“导入文件”区选择 `.csv` 或 `.xlsx` 文件，或直接拖放到页面中。
2. 可在“粘贴表格数据”中使用内置示例，或直接粘贴 CSV 文本后点击“导入粘贴数据”。
3. 在“脱敏规则”中启用需要处理的字段。
4. 选择脱敏方式：替换、置空或随机。
5. 点击“开始脱敏”。
6. 处理完成后页面自动滚动到预览区域，查看左右两侧的原始和脱敏结果。
7. 确认无误后，点击“确认并下载”导出文件。

## 内置测试数据

项目自带多组样例，用于验证以下情况：

- 正常结构化 PII
- 字段格式变体
- 中文姓名 / 地址 / 公司字段
- 自由文本中的隐私信息
- 误报陷阱与脏数据
- 多行/引号/空值/长文本输入

所有示例均为虚构测试数据，仅用于前端演示与功能验证。

## 备注

- 当前方案以“本地前端处理”为主，所有数据都在浏览器内存中完成。
- 模型资源与 tokenizer 均保存在本地目录，且会进行哈希校验。
- 原始文件不会被直接覆盖，导出的始终是新的脱敏副本。
