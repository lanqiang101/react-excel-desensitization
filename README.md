# 隐数台：CSV/XLSX 表格脱敏工作台

一个面向数据分析、产品运营、学生和案例文档制作的本地表格脱敏工具。
它帮助用户在对外分享表格前隐藏手机号、身份证号、邮箱和地址等敏感信息。

## 产品特点

- **本地处理**：文件只在当前浏览器内存中处理，原始文件不会上传服务器。
- **批量导入**：支持同时选择或拖放多个 `.csv`、`.xlsx` 文件。
- **粘贴导入**：支持直接粘贴 CSV 文本，保留引号、逗号和多行字段。
- **内置样例**：内置结构化 PII、格式变体、自由文本、误报陷阱、中文专项和脏数据 6 组测试表。
- **常用规则**：内置手机号、身份证号、邮箱地址、详细地址、中文姓名和公司名称规则。
- **灵活方式**：支持替换、置空、随机掩码三种脱敏方式。
- **规则模板**：支持选择标准个人信息、联系方式等规则模板。
- **原文件不变**：处理结果生成新文件，不修改用户导入的原始文件。
- **结果预览**：处理完成后先左右对比原始数据和脱敏结果，确认无误后才下载。
- **混合扫描**：正则负责确定性字段，MiniLM 负责未知文本列中的辅助识别；模型不可用时自动降级，不影响规则脱敏。
- **质量防护**：支持置信度阈值、黑名单过滤、正则优先裁决和脱敏后残留扫描。

- Vite 6

## 模型扫描说明

MiniLM-L6-PII 对中文姓名、地址和公司名的识别能力有限，因此模型扫描采用高置信度阈值、黑名单过滤和正则优先策略。模型状态分为：

- `MODEL_READY`：模型、词表和配置校验通过，WASM 推理 session 初始化成功。
- `MODEL_UNAVAILABLE`：模型资源缺失或 SHA-256 校验失败，仅使用规则引擎。
- `MODEL_DEGRADED`：资源存在但运行时初始化失败，仅使用规则引擎。

当前已引入完整模型目录，文件位于 `model/`，并同步到 `public/models/rampart/`：包括 `model.onnx`、`tokenizer.json`、`vocab.txt`、`config.json` 和特殊 token 配置。浏览器端通过 `onnxruntime-web` + WASM 加载模型，并对未知文本列执行 MiniLM 辅助扫描；模型及关联文件会进行 SHA-256 校验。本模型输入为 `input_ids`、`attention_mask`、`token_type_ids`，输出为 `logits[1,16,111]`。

文件处理时，手机号、身份证号、邮箱等正则命中区域不会重复交给模型；未匹配的文本才进行模型扫描。姓名、地址、公司等实体还会经过置信度、长度、数字占比和黑名单校验。

运行模型加载和张量输出测试：

```bash
npm run test:model
```

正则引擎始终是主流程和降级方案。模型权重和 tokenizer 均在浏览器本地加载，不上传用户表格数据。

## 使用流程

1. 在“导入文件”区域选择或拖放 CSV/XLSX 文件。
2. 或在“粘贴表格数据”中载入内置示例，或粘贴 UTF-8 CSV 文本后点击“导入粘贴数据”。
3. 在“脱敏规则”中启用需要处理的字段。
4. 选择脱敏方式和规则模板。
5. 点击“开始脱敏”，生成待确认的脱敏结果。
6. 在左右预览中检查原始数据与脱敏后数据，点击“确认并下载”导出新文件。

内置示例用于验证基础结构化 PII、格式边界、长文本召回、误报防控、中文实体和脏数据解析。示例数据均为虚构数据。
